# A simple terminal-based text editor

I love creating documents easily without using my mouse or any clunky GUI elements. Still, I don't feel like I need a full power editor like Sublime for most text tasks. And Nano always felt super awkward. (no control+a -> control+c functionality.)

Why use it?
- Never reach for the arrow keys. terminaleditor respects MacOS / Linux default control shortcuts.
- Extremely light and fast. ~30kb of Python.
- Saves file constantly so less risk of data loss.
- Best simple plain text documents like todo lists, meeting notes.
- MIT license and free what more do you want from me :)

Open issues to let me know if you catch any bugs or if you really really need a certain feature.
